# Notch Agent

A little friend that lives in your MacBook's notch (or as a small drop at the top center of an
external display). Hover it to see every live Claude Code and Codex session: approve or deny
tool permissions, answer an agent's questions, tell a finished agent what to do next, and jump
to the session in its app.

This repository only holds releases. Download the latest from
[Releases](https://github.com/spencersa09/NotchAgent-releases/releases/latest).

## Install

You need macOS 14 or later, and Claude Code (or Codex) already set up.

1. Download `Notch-Agent-<version>.zip`, unzip it and drag **Notch Agent** into Applications.
   It's signed and notarized, so it opens without a warning.
2. Open it. A pair of eyes appears in the notch, plus an icon in the menu bar.
3. Hover the notch and click **Connect Claude Code** (and **Connect Codex** if you use it).

Notch Agent checks for updates once a day and asks before installing them.
